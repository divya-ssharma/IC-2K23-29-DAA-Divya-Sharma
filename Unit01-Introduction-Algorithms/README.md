## Sorting

- Bubble Sort 
- Recursive Bubble Sort 
- Selection Sort 
- Insertion Sort 
- Recursive Insertion Sort 


Linear search works on unsorted arrays, but binary search needs a sorted array, so the two binary search files sort the input first. The recursive sorting variants are the iterative versions rewritten with a base case, same output, same complexity, just recursion instead of loops.
